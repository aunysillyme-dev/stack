# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Compute and Agentic stacks, with GPU clouds, inference APIs, coding agents, MCP, and agent frameworks.
- Design entries for AI image, UI builders, brand tools, and design-to-code, and video entries for newer generation, editing, upscaling, and lip-sync tools.
- A category taxonomy and table of contents in the README. Catalog entries use one format: name, link, one-line description, and a free, freemium, or paid tag.
- Release, security, maintainer and credit guidance, plus Scorecard and dependency updates.
- Validation on pushes to main and a success check for proposals.

## [0.1.0] - 2026-11-18

### Added

- Creative stack collection, contributor checks and workflow author credits.
- Curated Design stack and 13-category resource inventory.

### Changed

- Added contributor rights certification and improved the collection guide.
- Moved Video and Design collections to the repository root.
