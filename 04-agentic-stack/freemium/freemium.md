# Agentic tools stack: freemium resources

Tools and platforms with a free tier alongside paid upgrades.

Reviewed 2026-11-28 · 10 entries · Source: https://code.claude.com/docs/en/overview

- **[Claude Code](https://code.claude.com/docs/en/overview)**: Coding agent | Coding agent | Freemium (`freemium`): Agentic coding tool that reads a repo, edits files, and runs commands in the terminal, IDE, desktop app, or browser.
- **[Claude Code subagents](https://code.claude.com/docs/en/sub-agents)**: Coding agent | Feature | Freemium (`freemium`): Specialized workers inside one Claude Code session. Each returns a summary instead of filling the main context.
- **[Claude Code agent teams](https://code.claude.com/docs/en/agent-teams)**: Coding agent | Feature | Freemium (`freemium`): Experimental teams of Claude Code sessions with a shared task list and messages between teammates. Off unless enabled.
- **[Claude Code dynamic workflows](https://code.claude.com/docs/en/workflows)**: Coding agent | Feature | Freemium (`freemium`): Scripted orchestration that runs many Claude Code subagents and cross-checks their results.
- **[Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview)**: SDK | SDK | Freemium (`freemium`): Python and TypeScript library for the Claude Code agent loop, tools, permissions, and sessions.
- **[Jules](https://jules.google/)**: Coding agent | Coding agent | Freemium (`freemium`): Google's autonomous coding agent that plans a change in a GitHub repo and opens a pull request.
- **[OpenAI Codex](https://openai.com/codex/)**: Coding agent | Coding agent | Freemium (`freemium`): OpenAI coding agent for planning, building, reviewing, and shipping code across ChatGPT, the editor, and the terminal.
- **[Cursor](https://cursor.com/)**: Coding agent | Coding agent | Freemium (`freemium`): AI coding agent and editor for handing tasks to agents inside a repository.
- **[CrewAI](https://crewai.com/)**: Framework | Framework | Freemium (`freemium`): Framework and platform for crews of agents that share a task.
- **[OpenHands](https://docs.openhands.dev/)**: Coding agent | Coding agent | Freemium (`freemium`): Open-source coding agent with a cloud option that can work from GitHub issues.
