# Agentic tools stack: free resources

Free and open-access tools and resources.

Reviewed 2026-11-28 · 8 entries · Source: https://code.claude.com/docs/en/overview

- **[Model Context Protocol](https://modelcontextprotocol.io/)**: Protocol | Protocol | Free / open access (`free`): Open protocol for connecting agents to tools and data.
- **[MCP reference servers](https://github.com/modelcontextprotocol/servers)**: MCP server | Server | Free / open access (`free`): Official reference MCP servers maintained with the protocol.
- **[GitHub MCP server](https://github.com/github/github-mcp-server)**: MCP server | Server | Free / open access (`free`): GitHub's official MCP server for repository, issue, and pull request tools.
- **[Playwright MCP](https://github.com/microsoft/playwright-mcp)**: MCP server | Server | Free / open access (`free`): Microsoft's MCP server that lets an agent drive a browser through Playwright.
- **[Gemini CLI](https://github.com/google-gemini/gemini-cli)**: Coding agent | Coding agent | Free / open access (`free`): Open-source terminal agent that brings Gemini into the shell. API usage is billed by Google.
- **[Google ADK](https://adk.dev/)**: Framework | Framework | Free / open access (`free`): Open-source Agent Development Kit for building, debugging, and deploying agents.
- **[LangGraph](https://www.langchain.com/langgraph)**: Framework | Framework | Free / open access (`free`): Open framework for durable agent workflows, memory, streaming, and human review.
- **[AutoGen](https://github.com/microsoft/autogen)**: Framework | Framework | Free / open access (`free`): Microsoft's open programming framework for agentic applications.
